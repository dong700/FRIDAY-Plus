## 每个脚本演示的"坑"

| 文件 | 原本的坑 | 现在 |
|---|---|---|
| 01 | 端口写死会撞车 | 用 `DEMO_PORT`，默认 18080 |
| 02 | "今晚提醒我" 落在"现在这一分"（`hh` 改了但 `mm` 没重置） | **已修**：`mm = 0`，另补 `N 分钟后` 与"无日期按时段" |
| 03 | `_query_overlap` 按单字，"我/的/他"会虚抬所有条目 | 未改（保留为已知缺陷） |
| 04 | `你记错了` 会无差别罚最近 2 条；"不对"不触发 | 与源码一致，保留 |
| 05 | 同模板主动消息（`提醒你一下：X`）被相似度闸误杀 | **已修**：`dedup_key` 剥前缀；末段是回归用例 |
| 06 | 自动完成超时太短会把长活动切碎 | 最小版未启用超时 |
| 07 | Ollama 没起时必须降级为空，否则对话阻塞 | 脚本里显式 catch 并提示 |
| 08 | 模型给的 `arguments` 可能不是合法 JSON；工具名可能是编的 | 脚本演示三种兜底 |
| 09 | `raise last_err` 在 `retries=0` 时是 `raise None` | 默认 5 次，规避 |
| 10 | 未闭合的 `<memory>` 会被整段丢弃 | 保留（符合源码行为） |

## 阅读顺序

```
09 → 01 → 10 → 02 → 03 → 04 → 05 → 06 → 07 → 08
```

先地基（原子写、协议、流式过滤），再记忆（解析、挑选、纠错），再主动性（心智、活动），最后行动（检索、工具）。
