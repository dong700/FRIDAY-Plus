## 第一路：长时序连贯动作理解

**结论先行**：三条线（事件边界 / 分钟级活动理解 / 多视角融合）均有可直接借鉴的成熟工作。事件边界用"预测误差+自适应阈值"（ESTimator）；分钟级理解用"长短双窗记忆"（LSTR）；**事件级跨视角证据融合是研究空挡**——多视角方向只有数据集和物体级对应，无现成事件级方案，适合做我们的论文创新点。

## 第二路：记忆图是怎么构建的（TFGR 对标）

**结论先行**：TFGR 的"时序+因果+联想"三类边中，时序边和联想边是业界成熟做法；**因果边是 2026 年才出现的前沿方向**（Zep 产品级、MAGMA/ActMem 学术级），尚无标准抽取流程。边权重业界几乎全是启发式（共现计数/嵌入相似度/LLM打分），**未发现用梯度学习边权的主流工作**——TFGR 若做可学习边权，属于差异点。事实作废的共识是"**不删除、新作废**"（bi-temporal 四时间戳）。

### 2.1 图谱型记忆系统逐篇

**1. HippoRAG**（NeurIPS 2024, arXiv:2405.14831）
- 构建：离线用 LLM 做 OpenIE——先抽名词短语实体，再把实体填回提示抽 (主语,关系,宾语) 三元组；**边 = 三元组关系边 + 同义词边**（嵌入相似度链接，无显式标签）；边上权重由嵌入相似度/词频启发式给定。
- 检索：在线查询抽命名实体作种子节点，跑 Personalized PageRank 单步多跳。

**2. HippoRAG 2**（ICML 2025, arXiv:2502.14802）
- 在 1 基础上加**段落节点**：段落与其中短语全连接（dense-sparse 融合）；在线加"识别记忆"——LLM 过滤检索到的三元组再喂 PPR。
- 效果：多跳联想任务比最强嵌入模型平均 **+7.7 分**，兼顾事实类任务。

**3. GraphRAG**（微软, arXiv:2404.16130）
- 构建：LLM 对每个 ~600 token 分块抽实体+关系（多次 self-reflection 补召回）；**边 = 实体共现/关系，权重 = 共现计数累加**（无向加权图）；Leiden 层次社区检测 + LLM 社区摘要。
- 效果：全局问答对向量 RAG 胜率 72–83%。索引贵；LazyGraphRAG 把 LLM 延迟到查询时（索引成本 ≈0.1%）。

**4. LightRAG** (arXiv:2410.05779)
- LLM 逐块抽实体与带描述的关系边；同名实体合并去重（键+描述融合），增量更新/删档重建；双层检索（低层实体、高层主题）。**边无显式类型学，靠关系文本+度数**。

**5. Zep / Graphiti**（arXiv:2501.13956）——**与 TFGR 最相关**
- 三层子图：episode（原始消息）→ 实体 → 社区。LLM 抽实体和事实边。
- **每条边带 4 个时间戳**：valid_at（世界生效）/ invalid_at（世界失效）/ created_at / expired_at（系统习得），bi-temporal 双时间轴。
- **冲突处理 = 边作废不删除**：新事实与旧事实时间重叠矛盾时，把旧边 invalid_at 设为新边 valid_at，并**补建因果边**（如"鞋坏了→不满→改穿 Nike"）。
- 实体去重：名称+嵌入相似度判同、LLM 归并。检索 = 语义+BM25+图遍历（BFS/RRF），无 LLM 重排，<200ms。
- 官方称 LoCoMo 94.7%、LongMemEval 90.2%（**厂商数字，待核实**）。

**6. Mem0 / Mem0g**（ECAI 2025, arXiv:2504.19413）
- 非图主体：抽取-更新两段式，LLM 以工具调用对 top-s 相似旧记忆做 ADD/UPDATE/DELETE/NOOP。
- 图变体 Mem0g 用 Neo4j：实体节点+关系边+**时间边**（前/后时序）。LoCoMo J 值：Mem0 66.9、Mem0g 68.5、OpenAI Memory 52.9；时序题 Mem0g 58.1 领先（显式时序边的贡献）。
- 2026 版改 ADD-only 单趟抽取+时序重排，宣称 LoCoMo 92.5、LongMemEval 94.4（**厂商数字**）。

**7. A-Mem**（NeurIPS 2025, arXiv:2502.12110）
- Zettelkasten 卡片：每条记忆 7 字段（内容/时间戳/关键词/标签/上下文描述/嵌入/链接）；**边 = 链接**：top-k 余弦近邻 + LLM 判断是否建链（**二元，无权重**），再加"记忆进化"回写更新旧卡片属性。
- LoCoMo 时序 F1 25.52→45.85，token 省 85–93%。

**8. MemOS** (arXiv:2507.03724)
- 不做事实图：MemCube 统一明文/KV 激活/参数三类记忆，MemScheduler 调度、MemLifecycle 管生命周期（相似记忆合并、过期回收）。借鉴点在其**生命周期治理**而非边设计。

**9. 无图基线**：MemoryBank（AAAI 2024, arXiv:2305.10250）艾宾浩斯遗忘曲线+分层摘要，无图无边；MemGPT/Letta（arXiv:2310.08560）OS 分页（核心/召回/档案三层），冲突靠 LLM 文本合并；SCM（Self-Controlled Memory，2023，编号待核实）LLM 主干+记忆池+控制器三件套。

### 2.2 边设计与因果边的最新工作（2026）

- **MAGMA** (arXiv:2601.03236)：每条记忆拆成**正交的语义/时序/因果/实体四张图**，检索=策略引导的图遍历，宣称在 LoCoMo/LongMemEval 超 SOTA（**具体数字待核实**）。
- **ActMem** (arXiv:2603.00026)：记忆 KG 的边分**因果边+语义边**；语义边按相似度阈值连；因果边支撑反事实推理检测隐含冲突；自带 ActMemEval。
- **ContextWeaver** (arXiv:2604.23069, AWS)：把 agent 轨迹连成**依赖边**（工具输出/逻辑依赖），SWE-Bench pass@1 提升且省 token。
- **Kumiho** (arXiv:2603.17244)：AGM 信念修正落地——**不可变 revision 节点 + 可变 tag 指针**，依赖/时序/语义三类带型边；批判 MemGPT/Letta 的文本合并不可审计。

### 2.3 基准现状（重要提醒：跨论文数字不可直接比）

- **LongMemEval**（ICLR 2025, arXiv:2410.10813）：500 题、6 能力（单会话用户/助手/偏好、知识更新、时序、多会话）。GPT-4o 全历史 60.6%（oracle 87.0%）。2026 各家公开宣称 SOTA（Mastra 94.87、ByteRover 92.8 等）**多为厂商自报、评测口径不一，待核实**。
- **LoCoMo** (arXiv:2402.17753)：10 段长对话/272 会话、单跳/多跳/时序/开放域/对抗五类。各家 J 分数**跨论文不可直接比**（judge 模型与过滤方式不同）。
- 启示：我们若报数，应同时报 LongMemEval-S 并**公开 judge 配置**，避免沦为又一组不可比数字。

### 2.4 三问回答

**a) 业界主流边类型集合**：
① LLM 抽取的实体—关系三元组边（事实边，关系标签多为自由文本）；
② 同义/相似边（嵌入阈值）；
③ 实体↔段落/episode 溯源边；
④ 时序边（顺序/有效期，Zep 的 bi-temporal 最完整）；
⑤ 社区归属（GraphRAG 隐式）。
TFGR 的"时序+因果+联想"三分类中，前两类成熟；**因果边是 2026 前沿**，尚无标准抽取流程。

**b) 边权重普遍怎么定**：几乎全部启发式——共现计数（GraphRAG）、嵌入相似度（HippoRAG 同义边、ActMem 阈值）、LLM 打分、使用频次/时间衰减（MemoryBank、Mem0 decay）。**未发现用梯度学习边权的主流工作（待核实）**；A-Mem 干脆二值边。→ TFGR 做可学习边权 + 激活后压制，属于差异点。

**c) 事实更新/作废最佳实践**：共识是"**不删除、新作废**"——bi-temporal 时间戳 + 旧边置 invalid_at + 保留溯源（Zep/Graphiti）；写入口 LLM 工具调用判定 ADD/UPDATE/DELETE/NOOP（Mem0）；节点级方案用不可变版本+指针切换（Kumiho）。→ TFGR 的"写时一致 supersession"方向与 Zep 一致，可借鉴其**四时间戳字段**与"**冲突时补建因果边**"的细节。

**给 TFGR 的落位借鉴**：① 补段落/episode→事件溯源边；② 同义边用嵌入阈值自动建，省 LLM 调用；③ 因果边走 LLM 事件级抽取（PC/GES 类因果发现算法未见用于 agent 记忆图——待核实），避免全图因果发现的高成本；④ 报数口径：LongMemEval-S + 公开 judge 配置。

## 第三路：记忆怎么存储、怎么可微分

**结论先行**：最可行的组合是 **HippoRAG（可微 PPR 替换激活扩散）+ GNN-RAG/G-Retriever（可学习子图打分）**；只换打分器则 **EMDR2 式 EM 损失**最直接。训练信号**不能只靠稀疏用户反馈**——业界通行"伪标签自监督 + 答案内生奖励 + 归因过程奖励 + 用户反馈偏好对"四条腿。

### 3.6 三问回答

**a) 把"激活扩散+启发式打分"换成可学习打分器，业界最接近的方案**：
- 组合方案：**HippoRAG（可微 PPR 替换激活扩散）+ GNN-RAG/G-Retriever（可学习子图打分）**；
- 只换打分器：**EMDR2 式 EM 损失**最直接（答案似然作为可微目标）；
- 工程最近亲：**Memory-R1 的 Answer Agent（listwise 记忆蒸馏 + RL）**。

**b) 训练信号从哪来？仅靠稀疏用户反馈不够**。业界通行四条腿：
1. **伪标签自监督**（FiD-KD/Atlas 生成 QA 对、EMDR2 伪 Q-D 对、MemBuilder 合成 session 级 QA 稠密化奖励）；
2. **答案内生奖励**（EM/似然，Memory-R1 仅 152 对即可起效）；
3. **归因过程奖励**（AttriMem）与**内生预测误差**（Titans surprise、Memory-R⁺ 内在奖励）；
4. 用户反馈只作**偏好对（LeReT/DPO）或验证信号**，而非唯一 RL 奖励。

**c) 最小可行改造路径（工程成本三档）**：
- **低档（1-2 周）**：保留现有特征（recency/importance/relevance），把线性加权换成**可学习打分头**（logistic/小 MLP）；用历史会话让 LLM 造伪 QA，EMDR2 式 EM 损失离线训练；👍/🚫 做 Miconi 式塑性增量直接调边权（η 可学）。
- **中档**：激活扩散换 **PPR**（HippoRAG），边权按关系类型用 CompGCN 式嵌入参数化；👍/🚫 构造偏好对，LeReT 式 DPO 训 listwise 重排器；G-Retriever 式 PCST 控制注入规模。
- **高档**：整个"扩散+打分+过滤"作为策略，**GRPO 端到端训练**（Memory-R1/Mem-α 式），MemBuilder 式伪 QA 稠密奖励 + AttriMem 式归因，用户反馈与答案对错合并为混合奖励。

## 交叉比对：我们的位置、空挡与差异点

| 维度 | 业界现状 | 我们 (TFGR/ATG) | 判定 |
|---|---|---|---|
| 事件边界 | ESTimator 预测误差+自适应阈值（在线 F1 0.748） | 固定 15s 同源去抖窗口（工程补丁） | **应升级**：预测误差驱动切段，理论依据 Zacks EST |
| 分钟级活动理解 | LSTR 长短双窗、Mamba 骨架模型 | ST-GCN++ 秒级短窗 + 骨架序列长窗（已有两级栈雏形） | **方向一致**，LSTR 是理论模板，补齐接口 |
| 多视角融合 | 只有物体级对应（LM-EEC）和数据集（Ego-Exo4D） | 无 | **研究空挡**：事件级跨视角融合可作论文创新点 |
| 记忆图边类型 | 三元组+同义+溯源+时序成熟；**因果边 2026 前沿** | 时序/因果/联想三类（但实际只建了简单连线） | **对标前沿**：因果边按 LLM 事件级抽取落地，成本可控 |
| 边权重 | 全启发式，无可学习边权 | 启发式（共现/相似度） | **差异点**：可学习边权是空挡 |
| 事实作废 | bi-temporal 四时间戳 + invalid_at 不删除 | 写时一致 supersession（删旧沉淀新） | **方向一致**，补四时间戳字段与"冲突补建因果边"细节 |
| 检索机制 | PPR（HippoRAG）/ PCST（G-Retriever）/ GNN | 势能演化+激活扩散+启发式加权 | **可升级**：PPR 可微替换，或低档先换可学习打分头 |
| 记忆可微分 | NTM/DNC→TTT/Titans；RL 训记忆管理（Memory-R1 等） | 无（用户反馈桥刚起步） | **最大差距**，但低档路径 1-2 周可落地 |
| 防重复/打扰 | VideoLLM-online 的 skip 机制、Dispider 解耦 | 话题疲劳/激活后压制/RECENT_ACTIVE | **自研机制有特色**，可与 Dispider"何时说vs说什么"框架互证 |
| 遗忘 | MemoryBank 艾宾浩斯、Mem0 decay、Titans 遗忘门 | 势能时间遗忘+激活后压制 | **方向一致**，可升级为可学习遗忘门（DNC 式保留门） |

**三句话总结**：
1. **感知层**：我们修的"同源画面去抖"正对应业界事件边界方向，ESTimator 给出了标准答案（预测误差+自适应阈值），Zacks 理论背书；多视角事件级融合是真空挡，可做论文。
2. **记忆图**：TFGR 三类边对标 Zep/MAGMA 不落后，因果边是前沿；但"图怎么建"业界已给出成熟流程（LLM 抽三元组+嵌入同义边+溯源边），我们实际只建了简单连线，应补齐。
3. **可微分**：这是与业界差距最大的一块，但也是空挡最多的一块（可学习边权无人做）；低档改造（可学习打分头+伪QA+塑性增量）成本 1-2 周，训练信号不能只靠用户反馈。
