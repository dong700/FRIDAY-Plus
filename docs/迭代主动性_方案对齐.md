# 迭代主动性 · 方案对齐文档

> 目的：对齐「架构设计文档（方向C_00~C_06）」与「subbrain_demo 现状实现」的差距，评估 ProAct 可借鉴点，给出以 **M1 外界动态建模 + M2 副脑实时主动推理** 为核心的分阶段迭代路线，供用户审阅后选定切入点。
>
> 核心创意（用户原话）：「最主要的核心就是对外界的动态建模和副脑的实时主动推理，这个是核心创意点其他都是外接模块」。故本文聚焦 M1+M2，M3（主脑API桥梁）/M4（全模态）/M5（MCP）/M6（身体）均按外接处理。

## 一、ProAct 可借鉴点评估

**论文**：ProAct（北大 VCL，arXiv:2602.14048）双系统具身社交智能体，部署 Unitree G1。
**机制**：行为系统（快，GPT-4o Realtime + Flow Matching 动作生成）+ 认知系统（慢，后台 LLM 推理，固定周期 + 五维动机打分 + 阈值触发），三通道异步注入（手势意图/对话干预/移动控制）。

| 评估对象 | 结论 | 理由 |
|---|---|---|
| **Flow Matching** | **不借鉴** | 纯动作生成层技术（CFM 速度场 + ControlNet 解耦 + overlap-cache），属用户已划定的 M4 外接模块。既不建模世界（M1），也不做推理（M2），只是推理结果的"执行器"。验证了用户初步判断。 |
| **双系统快慢分离架构** | **借鉴思路** | ProAct 认知系统 = 用户"副脑"的已落地工程实例。后台慢推理 + 前台快响应解耦并行，可直接参考。 |
| **Context Encoder 有界记忆库** | **参考+超越** | 其"有界压缩记忆"对 M1 有参考价值（用户心智/情境追踪/历史行为三类），但实现浅（LLM 文本压缩，无时序/因果图）。用户做 TFGR 时间流图 + 因果链回写恰是差异化超越点。 |
| **ProAct 两大自认局限** | **战略定位锚点** | ① 触发机制=固定频率+阈值，非动机驱动；② 依赖云端 LLM，1-2s 延迟。这两点正好对应用户核心创意的差异化机会（动机驱动 + 本地化副脑），是最有力的"对比优势论证"素材。 |

**一句话**：Flow Matching 不借鉴（判断正确）；ProAct 作为最近期标杆，其**认知系统=副脑的工程范式、记忆库设计、以及它公开承认的两大局限**对论证自身核心创意独创性具有高参考价值——"别人做到了双系统分离，但触发机制和本地化正是我要突破的"。

## 二、架构设计文档要点摘要（设计侧基线）

### 2.1 M1 外界动态建模（方向C_01）

- **核心契约**：`PersonState` 12 字段（[方向C_01 L25-39](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_01_动态用户建模.md#L25-L39)）：`user_id, name, presence, attention, emotion_valence, emotion_arousal, last_speech_end, silence_duration, current_topic, unresolved_intents, known_facts, relationship`。
- **多人物**：`UserStateMap = Dict[user_id, PersonState]`，主用户固定 `key="user"`。
- **双路径**：10Hz 本地基线（<80ms/tick，规则+TFGR图，不调API）+ β 路径异步深度建模（经 M3 调主脑API做意图/关系推断，2-5s，不阻塞）。
- **角色**：M1 是状态生产者（写共享内存），M2 是消费者（内存读 ~5μs）。M1 挂了 M2 用最后快照降级。
- **定位**：M1 = "活着感"的感知基础，是 M2 决策"该不该说"的前提。

### 2.2 M2 副脑主动触发（方向C_02）—— 伪意识三支柱

设计明确声明：**主动触发不再是规则链**（旧版"R(e)低→FOLLOW_UP，R(e)高→CHECK_IN"是规则器套皮）。主动性来自三支柱耦合驱动：

**支柱① 内在状态层（§6.2-6.4）**：`self_state_predictor` 输出 V/PE_V（2维，[qwen_with_graph_bias_sst.py L458-462](file:///c:/Users/aodon/Desktop/基于时间流图的推理范式/tfgr_state_machine/models/qwen_with_graph_bias_sst.py#L458-L462)）；energy/arousal 来自 self_state_vector 分量与 w_energy 参数；V_drift = 1 - g(V)（[v40_arch.py L256-265](file:///c:/Users/aodon/Desktop/基于时间流图的推理范式/v40_arch.py#L256-L265)）。六字段 `V/PE_V/energy/confidence/arousal/V_drift` 暴露给动机生成层（[方向C_02 L386-445](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L386-L445)）。

**支柱② 主观时间层（§7）**：TFGR 图 R(e) 作为"记忆重量"进入动机公式（不再直接映射姿态）。双时钟融合（[§7.5 L755-795](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L755-L795)）只产出 `hard_trigger + 候选列表`：
- `silence > 300s ∧ presence` → `long_silence`（硬触发，动机 +0.2 加持）
- `silence > 60s ∧ presence` → `short_silence`（软候选）
- 旧 `_r_to_attitude` 规则链已删除。

**支柱③ 自我延续层（§4/§5）**：identity_cache（EMA β=0.9）+ W_probe（probe_self_attribution，[L1166](file:///c:/Users/aodon/Desktop/基于时间流图的推理范式/tfgr_state_machine/models/qwen_with_graph_bias_sst.py#L1166)）。V_drift 反向耦合到动机减法项。

**动机公式（§6.5，伪意识心脏，[L484-544](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L484-L544)）**：

```
motivation(e) = energy × R(e)⁻¹ × importance(e)     // (1) 维持性动机
              + PE_V × relevance(e)                   // (2) 探索性动机
              + arousal × closeness(e)                // (3) 关系性动机
              - V_drift × 2.0                          // (4) 自我不稳定抑制
```
- 返回 `(strength, type ∈ {maintenance, exploration, relational})`，~0.5ms/候选。
- 类型→姿态：maintenance→FOLLOW_UP，exploration/relational→CHECK_IN。
- 阈值门控：`max_motivation ≥ θ_active`→主动；`∈[θ_silence, θ_active)`→SILENCE(预计算倾向)；`< θ_silence`→SILENCE。

**无聊分支（§6.6，[L546-620](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L546-L620)）**：`is_bored = energy<0.3 ∧ presence ∧ silence>120s ∧ V_drift<0.4` → 动机类型 `exploratory_play`，`m = (1-energy)*2*entertainment_value + PE_V_abs*novelty - V_drift*2`。

**CausalPlan 时间因果闭环（§10.5-10.7，[L967-1039/L1523-1665/L1917-2007](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L967-L1039)）**：
- §10.5 `CausalPlan`/`PlanStep`/`PlanAction`：跨 tick 因果链，5 步 `reason(意图)→reason(记忆检索)→act(执行)→observe(跨tick等待)→adjust(回写图)`，每步有 precondition 依赖前一步。
- §10.6 `PlanExecutor.tick(now, user_state) → Optional[DialogueIntent]`（[L1649-1665](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L1649-L1665)）：跨 tick 推进 reason→act→observe→adjust，observe 跨 tick 等待用户反应（不增单 tick 预算），adjust 根据观察修改后续步骤。
- §10.7 因果链回写 TFGR 图：plan 完成/中止时整条因果链作为复合事件节点回写图，带 `entertainment_value/success_score/importance`，~5ms，下个 tick 即可被检索（[L1917/L2007](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L1917-L1920)）。这是闭环关键——让"经验"在图中沉淀。

**β tick 决策环（§8.1，[L803-828](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_02_副脑主动触发系统.md#L803-L828)）**：
`感知层(读UserState+候选) → 内在状态层(self_state_predictor) → 动机生成层(§6.5) → 姿态决策层(阈值门控) → 自我延续检查(W_probe) → 输出 DialogueIntent 或 SILENCE`

### 2.3 M3 主脑API桥梁（方向C_03，外接）

`GenerationRequest(intent + context_bundle + identity_cache_snapshot + safety_mode)` → 主脑API流式 → `GenerationStream`（W_probe 生成后异己检测过滤 token）→ `AlienReport(v_drift, regenerated)`。M3 无状态，是 M2 与外部API唯一桥梁。**W_probe 阈值**：cos(h_self,W_probe)=+0.091，cos(h_alien)=-0.089，建议 θ_safety=0.0（[方向C_03 L430-508](file:///c:/Users/aodon/Desktop/Active_AI_Plus/架构设计指导文档/方向C_03_API辅助思考.md#L430-L508)）。

### 2.4 M4/M5/M6（方向C_04/05/06，外接）

全模态交互 / MCP工具生态 / 物理身体控制。均为外接模块，消费副脑输出的高层 DialogueIntent，不在核心创意范围内，本文不展开。
