# 视觉长时序理解现状调研（聚焦：连续看用户）

> 调研时间：2026-09-14。背景：作者澄清"长时序理解主要是视觉"——摄像头连续看下去，怎么从"看帧"变成"理解持续在发生什么"。当前我们的感知层是"单帧截图→Qwen-VL描述→15s去抖合并"。本文收罗三路证据：离线长视频 LLM、流式/实时视频理解、第一视角/全生命周期视觉记忆与端侧可行。所有条目经搜索核实，未能确凿核实的标"待核实"。

---

## 总判断（先说结论）

1. **行业天花板很低**：小时级离线视频 QA 普遍 <60%，天级（>24h）结构化理解全世界最远 ~35%（EgoRAG）；"预测接下来做什么"（LTA）动作级准确率仅 15~36%。**视觉长时序理解是全行业未解决问题，不是我们的短板独有。**
2. **业界共识已形成**：固定间隔解码必然重复、均匀采样必丢事件——"输出必须由变化触发"已是 2025-2026 的主流结论（TimeChat-Online 实测流式视频 80%+ 视觉 token 冗余）。
3. **我们的"单帧+去抖"不是土到没朋友**：NVIDIA DeepStream 工业默认就是"VLM 每 10 秒取 1 帧→文本摘要"（稀疏采样+文本记忆）；EgoSchema 榜单证明"逐段 caption→LLM 聚合"的代理管线已把 3 分钟级 QA 推到人类水平（~75%）。但它是离线范式的退化版，升级路径明确。
4. **空挡确认**："端侧事件触发→VLM→活动区间→跨天作息记忆"的完整在线闭环，没有任何系统做到。学术最接近的 LightMem-Ego（作息发现）只是 demo；工业无产品。**窗口期约 1-2 年**（流式 VLM 正快速下沉）。

## 第一路：离线长视频理解 LLM（天花板参照系）

### 基准与 SOTA

| 基准 | 时长量级 | 当前最好水平 | 说明 |
|---|---|---|---|
| Video-MME (CVPR'25) | 11s–1h，长档30–60min | Gemini 1.5 Pro 75.0%（长档仅67.4）；GPT-4o 71.9（65.3）；开源7B VideoLLaMA3 66.2（长档55–56） | 官方结论：所有模型随时长增加性能下滑 |
| MLVU (2024) | 3min–2h | GPT-4o 仅 54.9%（M-AVG） | |
| LVBench (智谱2024) | 小时级 | GPT-4o 48.9；最强为 agent 式 Deep Video Discovery 74.2（微软2025，大算力多轮回看） | 容量≠理解：Gemini 1M token 长档反而67.4 |
| EgoSchema (NeurIPS 2023) | 第一视角3min | HCQA 75%（人76%） | "逐段caption→LLM聚合"已推到人水平 |
| LongVideoBench (NeurIPS 2024) | 8s–1h | GPT-4o 66.7（900s+档降至61.6） | |

### 代表性方法（压缩思想）

- **LLaMA-VID**（ICLR'24）：每帧压成 2 token（context+content），支持小时级。→ 每事件段极低 token 表示。
- **MovieChat**（CVPR'24）：仿 Atkinson-Shiffrin 双记忆——短期 FIFO token 缓冲，满后按相邻相似度加权合并入长期记忆；免训练 24GB 卡处理 10K+ 帧。→ **短期/长期分层+合并式遗忘，与 ATG/TFGR 同构，可直接映射**。
- **MA-LMM**（Meta 2024）：在线逐帧编码，特征入长期 memory bank 供 LLM 查询。→ 在线+记忆库，天然流式友好。
- **LongVU**（Meta 2024）：DINOv2 相似度去冗余帧→文本查询引导选高分辨率帧→空间削减，8K 上下文容纳小时级。→ **用便宜特征做变化检测，编码预算只给"变化"**。
- **Video-XL**（BAAI 2024）：VST 摘要 token 周期性收敛 KV，16×压缩损失小；Video-XL-2（2025）chunk 稀疏注意力+按块重载 KV，A100 上万帧。→ 流式 KV 管理现成方案。
- **VideoChat-Flash**（2025）：HiCo 分层压缩（clip级→视频级），开源首个 10K 帧 NIAH 99.1%。
- **时序定位**：TimeChat（ICML'24，时间戳感知帧编码+滑窗Q-Former）、Momentor（AAAI'24，区间=token span）、VTG-LLM（绝对时间token）；**Qwen2.5-VL 动态FPS+绝对时间编码，官方称>1h视频秒级定位**。→ "他几点开始做饭"这类问题需要绝对时间戳绑定。
- **VAP 主动感知思想**：约 90% 查询注意力集中在 5% 的帧——证据稀疏且位置不可预知 → **用"预期差"替代 query-aware 采样：与预测不符的画面才升级编码**。这是流式下"不知道要问什么"的解法。

### 离线方法的三个根本短板（为何不能直接搬）

1. **帧率vs深度**：均匀采样必丢瞬时事件；强压缩几乎全部假设"问题已知"（query-aware）才做得动筛选。
2. **重复日常活动聚合未解决**：计数/顺序/异常类任务在 LVBench/MLVU 最差；"反复出现的做饭流程能否正确聚合"是 VideoLucy/EgoMem（2025）刚提出的新方向，尚无成熟答案。
3. **离线vs流式本质差异**：离线可全局随机访问、多轮回看；流式必须因果、单遍、低延迟且**问题未知**。STC（2025）实测流式瓶颈在 ViT 编码、在线视频时间冗余更高。

**结论：不能搬离线系统本身，只能搬它的记忆组织方式**（分层记忆、KV摘要、便宜特征变化检测、绝对时间戳）。

## 第二路：流式/实时视频理解（最贴我们）

### 基准

- **StreamingBench**（清华，arXiv:2411.03628）：首个流式 MLLM 基准，18任务/900视频，按时间戳分段提问。Gemini 1.5 Pro 70.26（实时项77.39），GPT-4o 64.10，远低于人类。→ 其"流式≠离线拼接"论证可直接引用。
- **OVO-Bench**（CVPR 2025, arXiv:2501.05510）：三档——Backward 回溯 / Real-Time 实时感知 / **Forward 主动延迟应答（等证据足够再答）**。→ Forward 档就是"何时开口"的学术化表达。

### 流式架构三类（业界主干）

**流式对齐对话类**
- **VideoLLM-online**（CVPR 2024）：LIVE 框架，special token 实时决定"输出/保持静默（Keep silent）"；5min 视频 10-15FPS（A100）。→ **静默 token 是防重复描述的正规解法**。
- **Dispider**（CVPR 2025）：解耦感知/决策/反应——轻量模块持续监看+触发头决定何时交互，触发后**异步**生成详细回答，监看不中断。→ **触发（便宜常开）与生成（贵偶发）分离，是陪伴机器人省算力的正解**。
- **StreamChat**（NVIDIA 2024，cross-attention 每解码步刷新视觉上下文；另有大工 2025 training-free 分层记忆同名工作）。

**KV/记忆压缩类**
- **Flash-VStream**（CVPR 2025）：空间/时间/摘要/检索四层记忆+双异步进程。→ 低容量时间摘要+高容量细节检索的分层。
- **LiveVLM**（arXiv:2505.15269）：training-free 流式 KV cache+在线检索，同卡帧数×44。→ 不改模型只改 KV 管理，工程友好。
- **StreamingVLM**（MIT/NVIDIA, arXiv:2510.09608）：attention sink+短视觉窗口 KV 复用，H100 8FPS 无限流。
- **TimeChat-Online**（北大，arXiv:2504.17343）：DTD 差分 token 丢弃——**流式视频 80%+ 视觉 token 冗余，丢弃 82.8% 仍保 98% 精度、延迟↓1.76×，低丢弃率天然标识场景切换**。→ 端侧最可行的"变化检测"思想。

**事件驱动类**
- **Event-VStream**（CVPRF 2026）：把视频表示为**离散事件序列**，融合运动+语义+预测线索检测状态跃迁，**仅在事件边界触发 LLM 生成**，事件嵌入写入持久记忆库。OVO-Realtime 比 VideoLLM-online-8B 高 10.4 分。→ 与我们设想的"事件驱动采样"几乎同构，**可直接引用其结论：固定间隔解码产生重复输出**。

**重要旁证**：SimpleStream（2026）——仅喂最近 4 帧的朴素基线在 OVO-Bench 达 67.7%、StreamingBench 80.59%，超过多数复杂流式模型。→ **感知-记忆权衡：历史越多实时感知常越差；浅层实时+深层异步复核两档制是共识。**

### 三问作答

**a) 主干架构三件套**：① 采样：变化/事件驱动 token 化（DTD、Event-VStream），非均匀帧；② 记忆：分层（近期细粒度窗口+长期摘要/事件库，KV压缩+按需检索回取）；③ 响应：感知-决策-反应解耦的异步双进程+显式触发头。

**b) 我们"单帧+去抖"的最小升级路径**：把"15s去抖"升级为"**变化触发的事件段描述+事件记忆写入**"——低成本帧差/token差分做触发器（TimeChat-Online 思想），仅变化时调 Qwen-VL 生成带时间戳的事件句，追加进事件库并做重复抑制（静默机制），跨时段参考 Event-VStream/Dispider 结构。**全程复用现有单帧模型，端侧可行。**

**c) 事件驱动采样是不是空挡**：**单独的事件驱动采样已有人做**（Event-VStream、Mage-VL）；但"轻量稀疏采样+活动级事件输出+跨日重复模式聚合"的完整组合（尤其面向老人的活动规律抽象）无现成系统——EgoMemReason/MM-Lifelong（ICML 2026，月级最好仅~17%）这类基准恰恰证明该能力缺失。**此处是可占的空挡。**

## 第三路：第一视角/全生命周期记忆 + 端侧（产品参照系）

### 学术最远

- **EgoLife**（NTU 等，CVPR 2025）：6 人戴 Aria 眼镜同住 7 天约 300h ego 数据+15 个第三人称相机；EgoGPT+EgoRAG 把 **>24h 跨度问题准确率从 25.0 提到 35.4**（Gemini-1.5-Pro 仅 18.4%）；作者自认 caption 质量是关键瓶颈。→ **天级结构化理解 ~35% 就是当前人类天花板，且全在云端**。
- **Ego-R1**（2025.6）：RL 训练工具调用 agent 做周级视频推理，EgoLifeQA ~36%。→ "分步调用检索工具"是长时程问答主流范式，但全在云端 GPU。
- **EgoMem**（2025.9）：首个终身记忆 agent——人脸/声纹识别→检索长期档案→异步抽取"事实/偏好/关系"更新记忆库；检索>95%、事实一致性>87%（自建测试）。
- **LightMem-Ego**（浙大+联想，2026.7 demo）：流式多模态记忆，当前/短期/长期三级+检索路由，部署于手机和 AI 眼镜，支持**作息发现（routine discovery）**——与看护最贴近，但为演示系统无公开精度。→ **唯一对标 TFGR 作息建模的工作，且只是 demo**。
- **LifelongMemory**（NYU 2023）：逐段 caption→LLM 构建情节记忆，开"文本化记忆"先河。
- **工业**：Limitless Pendant 仅音频（已被 Meta 收购）；**"连续数天视觉记录+结构化理解"没有产品级系统**。
- **Mage-VL**（Microsoft，2026.7）：codec 原生——用**运动向量+残差能量**选 patch，视觉 token 省 75%，"轻量 System-1 事件门+System-2 因果解码"双系统。→ 与我们路线同向，但未在居家看护闭环落地。

### LTA 长时动作预期（主动关怀的能力上限）

Ego4D LTA 2025 冠军（鹏城+哈工深，arXiv:2506.02550）：三阶段 EgoVLP→Transformer 预测 verb/noun→LLM 生成未来动作序列。**动作级准确率仅 15.36%（Action）/30.90（Verb）**。→ "预测老人接下来做什么"学界仍不成熟；**主动关怀应把预期粒度放宽到"活动区间/作息"级别**（正是 ATG 的做法）。

### 端侧可行路径

- **AKS**（CVPR 2025）及后续 F2C/AdaRD-Key/DIG：关键帧采样成熟研究线，但均假设完整视频已存好+通常需 GPU 算 CLIP 相似度。
- **帧差+MobileNet** 在 Jetson Orin Nano/Hailo-8 上：比端到端准确率+28.3%、效率3.6×、延迟-39.3%（2026）；TSM（MIT）Jetson Nano 在线识别 13ms/76fps。→ **便宜触发器在 NPU 级硬件可行**。
- **NVIDIA DeepStream** 官方示范："VLM 每 10 秒取 1 帧→按分钟批处理→文本摘要→Kafka"——**稀疏采样VLM+文本记忆已是工业默认**，但无事件触发与活动区间建模。

### 居家老人看护 ADL 现状

- 受控环境：摔倒/踉跄/胸痛/正常四类 TimeSformer 宏F1 95.33%（2025）；3D CNN 自建数据 97%——但类目少、受控光照。
- **Dignity-Aware position paper（2025.11）明确指出：业界停留在摔倒检测，ADL 专用数据集"仍在收集中"**；卡点为域偏移、数据稀缺、隐私。
- 作息级长周期建模（周级规律/偏离检测）：学界基本空白，仅 EgoLifeQA habit 类问题（~35%）。

## 交叉比对：我们的位置、空挡与升级路线

### 与三路现状的对照

| 我们 | 业界对应 | 判定 |
|---|---|---|
| 单帧截图→Qwen-VL | DeepStream 工业默认（10s/帧+文本摘要）；EgoSchema 代理管线的最小单元 | 不丢人，但是离线范式退化版，需升级 |
| 15s 同源去抖合并 | VideoLLM-online 静默token / TimeChat-Online DTD / Event-VStream 事件触发 | **业界共识"由变化触发"，去抖只是最糙近似** |
| ATG 活动区间建模 | AKS/F2C key clip 选择；LTA 时序建模；无人做成流式在线系统 | **空挡2：采样-区间-记忆三级贯通的在线系统无人做** |
| TFGR 作息/规律沉淀 | LightMem-Ego routine discovery（仅demo）；EgoMemReason behavior memory（~40%） | **空挡3：看护场景的作息结构化记忆无人做** |
| 事件驱动采样设想 | Event-VStream 已做（GPU端7B）；Mage-VL 运动向量门 | **不是空挡**，但"端侧NPU级事件触发→VLM闭环"没人做——**空挡1** |

### 三个空挡（可占位）

1. **端侧事件触发→VLM 闭环**：帧差/运动向量便宜触发器在 Hi3516/Jetson 级硬件上跑，仅变化时调用 VLM——业界全在 GPU/云端。
2. **流式在线的"采样→活动区间→记忆"三级贯通**：EgoRAG/LifelongMemory 全是离线；Event-VStream 有事件库但无活动区间与作息层。
3. **看护场景的天级作息结构化记忆**：TFGR 恰好是现成的记忆层，对标 LightMem-Ego 但我们有 ATG 供给活动级事件、有老人场景验证。

### 风险与窗口期

流式 VLM（StreamingVLM/InfiniteVL/MOSS-VL-Realtime）正快速降低长流理解门槛；Mage-VL 类 codec 原生方法也在逼近。若其下沉到端侧，**纯管线型创新的窗口约 1-2 年**。应把贡献押在"**端侧事件触发+天级作息结构化记忆+看护场景验证**"这一无人占据的交叉点上——这三件事叠加正好是我们的 ATG+TFGR+边缘部署积累。

### 最小升级路线（视觉链路，工程量从低到高）

1. **变化触发器**（帧差/低频特征比对本就有雏形）：替换固定 15s 轮询→"画面稳定不调用 VLM，变化才生成"。依据 TimeChat-Online（80% token 冗余）与 Event-VStream（固定间隔必重复）。同时解决 token 成本与重复描述。
2. **事件段描述带绝对时间戳**：对齐 Qwen2.5-VL 绝对时间编码/TimeChat 思想，事件句进 ATG 时携带 {开始/结束/来源}，为"几点开始做饭"级查询打底。
3. **静默与分级响应**：感知-决策-反应解耦（Dispider）——触发器常开（便宜）、活动区间更新（中频）、主动关怀生成（低频异步，等证据足够，对应 OVO Forward 档）。
4. **跨天作息聚合**：ATG 区间沉淀→TFGR 作息节点→离线重放周期做规律抽取（对应 MM-Lifelong 指出的月级~17% 空白）。这一步与脑学调研的"固化五步"直接对接。
